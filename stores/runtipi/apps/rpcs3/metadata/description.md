# Rpcs3

![Rpcs3](https://raw.githubusercontent.com/linuxserver/docker-templates/master/linuxserver.io/img/rpcs3-logo.png)

[RPCS3](https://rpcs3.net/) is a multi-platform open-source Sony PlayStation 3 emulator and debugger written in C++ for Windows, Linux, macOS and FreeBSD.

## Application setup

The application can be accessed at:

* https://yourhost:3001/

**Note: for gamepads to function select SDL as the gamepad driver under "Handlers".**
