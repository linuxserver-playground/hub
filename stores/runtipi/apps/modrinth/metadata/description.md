# Modrinth

![Modrinth](https://raw.githubusercontent.com/linuxserver/docker-templates/master/linuxserver.io/img/modrinth-logo.png)

[Modrinth App](https://modrinth.com/) is a unique, open source launcher that allows you to play your favorite mods, and keep them up to date, all in one neat little package.

## Application setup

The application can be accessed at:

* https://yourhost:3001/

**This image can function without a GPU, but we highly recommend only using this with a GPU**

Image: `ghcr.io/linuxserver-playground/modrinth:latest` ([https://github.com/linuxserver-playground/docker-modrinth](https://github.com/linuxserver-playground/docker-modrinth))
