# Rustdesk

![Rustdesk](https://raw.githubusercontent.com/linuxserver/docker-templates/master/linuxserver.io/img/rustdesk-logo.png)

[RustDesk](https://rustdesk.com/) is a full-featured open source remote control alternative for self-hosting and security with minimal configuration.

## Application setup

The application can be accessed at:

* https://yourhost:3001/

**Note: This is the Desktop application in a web accessible format! This container is for running the client in a sandbox so it does not have access to your system. It is not a server solution!**

Image: `ghcr.io/linuxserver-playground/rustdesk:latest` ([https://github.com/linuxserver-playground/docker-rustdesk](https://github.com/linuxserver-playground/docker-rustdesk))
