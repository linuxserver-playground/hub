# Shadps4

![Shadps4](https://raw.githubusercontent.com/linuxserver/docker-templates/master/linuxserver.io/img/shadps4-logo.png)

[shadPS4](https://shadps4.net/) is an early PlayStation 4 emulator for Windows, Linux and macOS written in C++.

## Application setup

The application can be accessed at:

* https://yourhost:3001/

**This image should be run with a GPU**

Image: `ghcr.io/linuxserver-playground/shadps4:latest` ([https://github.com/linuxserver-playground/docker-shadps4](https://github.com/linuxserver-playground/docker-shadps4))
