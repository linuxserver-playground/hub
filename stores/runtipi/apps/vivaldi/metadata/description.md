# Vivaldi

![Vivaldi](https://raw.githubusercontent.com/linuxserver/docker-templates/master/linuxserver.io/img/vivaldi-logo.png)

[Vivaldi](https://vivaldi.com/) is a Norwegian freeware, cross-platform web browser with a built-in email client developed by Vivaldi Technologies.

## Application setup

The application can be accessed at:

* https://yourhost:3001/
