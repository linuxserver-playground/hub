# Github-desktop

![Github-desktop](https://raw.githubusercontent.com/linuxserver/docker-templates/master/linuxserver.io/img/github-desktop-icon.png)

[Github Desktop](https://desktop.github.com/) is an open source Electron-based GitHub app. It is written in TypeScript and uses React.

## Application setup

The application can be accessed at:

* https://yourhost:3001/
